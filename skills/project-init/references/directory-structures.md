# Project Directory Structures

Literal directory-tree skeletons for Step 3. Create the tree matching the platform/framework selected in Step 0.5 and Step 1-B, in the current working directory. `.gitkeep` files maintain empty directories.

## Trees in this file
- Web platform
- Mobile — React Native / Expo
- Mobile — Flutter
- Mobile — Kotlin Multiplatform (KMP)

## Web platform

```
{project-root}/
├── CLAUDE.md
├── .claude/
│   └── settings.json
│
├── docs/
│   ├── design-system/
│   │   ├── DESIGN.md              # SSoT (YAML Front Matter + Markdown Body) — generated by /design-init
│   │   ├── components.md          # Legacy detail reference — superseded by DESIGN.md §4
│   │   ├── layout-grid.md

│   ├── blueprints/

│   │       └── blueprint.md
│   │

│   │   └── .gitkeep               # Planning deliverables (/service-planner)
│   │
│   ├── database/
│   │   ├── database-design.md
│   │   ├── naming-rules.md
│   │   └── migration/
│   │       └── .gitkeep

│   │   │   └── sprint-1/
│   │   │       └── .gitkeep
│   │   └── test-reports/
│   │       └── .gitkeep
│   │
│   ├── sprints/
│   │   └── sprint-1/
│   │       └── .gitkeep
│   │

│
└── src/
    ├── styles/

    └── .gitkeep
```
