# UAT Report i18n strings

Single source of truth for translatable strings used by `/user-test` and `/uat-parallel` when generating `index.html` and `issues.md`. Both skills read this file and apply substitutions based on the `lang` chosen at Step 0 (Language Selection).

Supported languages: `vi` (Tiếng Việt — default), `en` (English), `ko` (한국어).

## Substitution contract

When rendering the HTML report from `skills/user-test/assets/report-template.html`:

- `{{LANG}}` → BCP-47 short code (`vi` / `en` / `ko`)
- `{{T_*}}` placeholders are replaced with the values below

When rendering `issues.md`, use the same strings dictionary (markdown headings + labels).

## Notes

- Severity badge labels (CRITICAL / HIGH / MEDIUM / LOW) stay untranslated — they are technical taxonomy terms used identically across QA tooling.
- UAT case file content (under `docs/tests/uat-cases/`) is **not** translated by this dictionary — the case author writes them in whichever language suits the team. Only the *report wrapper* (chrome, labels, generated messages) is localized.
- File slugs and identifiers (UAT-IDs, screenshot filenames) remain ASCII regardless of `lang`.
- The default `lang` is `vi` when neither `--lang` is provided nor the user picks one (preserves backward compatibility).
